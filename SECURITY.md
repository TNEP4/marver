# Security policy

## Supported versions

Only the latest published version of `@marver-design/marver` receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security reports. Use GitHub's private
vulnerability reporting on this repository ("Security" tab → "Report a vulnerability").

Reports touching these surfaces are especially welcome:

- the published-canvas password gate and session cookies (`marver serve`)
- viewer accounts, invites, and comment sync
- the Live Jam trust boundary (owner-device ledger, agent sandboxing, reply extraction)

You'll get an acknowledgement within a few days, and credit in the changelog if you want it.
