# Marver for Mac - test releases

Test builds of the [Marver](https://github.com/TNEP4/marver) Mac app: spikes and release candidates, versions 0.9x.
They update only from this repository, never from the real one.

**Not for use.** The app is at [TNEP4/marver-app](https://github.com/TNEP4/marver-app); its source is in
[`app/`](https://github.com/TNEP4/marver/tree/main/app) of the Marver repository, and issues go
[there](https://github.com/TNEP4/marver/issues).
